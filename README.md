# Bikeshare Project

## Overview
This project analyzes bikeshare data from Chicago, New York City, and Washington. Users choose a city, month, and day, then the program displays statistics about travel times, stations, trip durations, and users.

## Files
- bikeshare.py: Main Python program
- README.md: Project documentation
- .gitignore: Prevents CSV files from being uploaded
- chicago.csv, new_york_city.csv, washington.csv: Local data files ignored by Git

## Requirements
- Python 3
- pandas

## How to Run
python bikeshare.py

## Features
- Time statistics
- Station statistics
- Trip duration statistics
- User statistics
- Raw data display
